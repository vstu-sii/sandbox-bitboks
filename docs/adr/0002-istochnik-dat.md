# ADR-0002. Даты партнёров — из таблицы кафедры

**Статус:** принято, 3 октября 2026

## Контекст

Свободные даты партнёры сейчас пишут в общую таблицу кафедры.

## Решение

Бот читает таблицу раз в сутки, а не ведёт свою базу дат.

## Альтернативы

- Своя база и кабинет партнёра: точнее, но партнёров ещё надо уговорить.

## Цена решения

Данные отстают до суток: студент может записаться на дату, которую партнёр
уже закрыл в таблице. Сутки — потому что чаще таблицу никто не обновляет.
