# ADR-0001. Бот в Telegram, а не веб-форма

**Статус:** принято, 2 октября 2026

## Контекст

Студенты кафедры записываются на практику через общую таблицу и чаты.
Нужен канал, где студент уже есть и где можно уточнить недостающее.

## Решение

Бот в Telegram.

## Альтернативы

- Веб-форма на сайте кафедры: проще сделать, но не переспросить и не напомнить.
- Бот во ВКонтакте: студентов там меньше, API неудобнее для кнопок.

## Цена решения

Зависим от Telegram: если он недоступен, записаться нельзя — запасной путь
остаётся таблица кафедры. Порог входа: студент без Telegram не запишется.
