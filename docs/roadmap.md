# Роадмап

## MVP — к работе 3

- Запись, перенос и отмена записи (UC-01–03) в Telegram.
- Партнёры и свободные даты — из общей таблицы кафедры, обновление раз в сутки.
  Даты бот берёт только из таблицы — модель их не придумывает. *(v2)*
- Недостающие данные бот спрашивает один раз, без бесконечных переспросов.
- Уведомление о свободных местах — подписка, сообщение в Telegram раз в день.
  *(v2: было письмо — в e2e ушло в спам у 2 из 3)*

## Не-скоуп MVP

Чего в MVP сознательно нет — и почему:

- **Другие мессенджеры и веб-версия.** Студенты кафедры в Telegram; второй
  канал удваивает поддержку без новых пользователей.
- **Выбор практики по резюме.** Нужна модель подбора и данные о партнёрах,
  которых нет; сначала проверим, что запись вообще нужна.
- **Оценка практики партнёром.** Это другой процесс и другой пользователь.
- **Голосовые сообщения.** Распознавание речи — отдельная работа и цена.

## После MVP

- Напоминание накануне практики.
- Отчёт кафедре: кто куда записан.
