## Долг, который оставляем осознанно

- **Таблица кафедры обновляется раз в сутки.** Цена: до суток студент может
  видеть место, которое уже заняли напрямую через кафедру. По прошлому
  семестру — примерно 1 запись из 20 сорвётся, студента перезапишем вручную.
- **Нет повторных попыток, если Telegram API не ответил.** Цена: при сбое
  Telegram запись не подтвердится, студент напишет заново. Сбоев за месяц
  прогонов — ни одного; чинить сейчас дороже, чем терпеть.
- **Evals гоняем руками перед релизом, не в CI.**
