# UC-02. Перенести запись

**Актор:** студент, уже записанный на практику.
**Цель:** перенести дату, не теряя место у партнёра.

## Основной сценарий

1. Студент пишет «перенести запись».
2. Бот показывает текущую запись и свободные даты у того же партнёра.
3. Студент выбирает новую дату.
4. Бот подтверждает перенос и освобождает прежнюю дату.

## Альтернативы

- 2а. У партнёра нет других дат — бот предлагает отменить запись или
  посмотреть других партнёров.
- 2б. Выбранную дату бот держит за студентом 10 минут, пока тот
  подтверждает; не подтвердил — место освобождается, бот пишет об этом.
  *(v2, после валидации на прототипе: два студента заняли одну дату)*
