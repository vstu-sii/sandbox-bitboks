# UC-03. Отменить запись

**Актор:** студент, записанный на практику.
**Цель:** отменить запись, чтобы место досталось другому.

## Основной сценарий

1. Студент пишет «отменить запись».
2. Бот показывает запись и спрашивает подтверждение.
3. Студент подтверждает.
4. Бот отменяет запись и сообщает партнёру.
