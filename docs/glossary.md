# Глоссарий

Термины, которыми команда пользуется в коде и документах.

- **Партнёр** — организация, которая принимает студентов на практику по договору с вузом.
- **Место** — одна свободная позиция у партнёра на конкретную дату.
- **Запись** — закреплённое за студентом место.
- **Переспрос** — повторный вопрос бота о недостающих данных; не больше одного.
- **Не-скоуп** — то, что сознательно не делаем в MVP, с причиной.
